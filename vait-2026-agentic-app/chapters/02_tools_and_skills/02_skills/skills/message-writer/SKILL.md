# Message writer

1. Work out who the message is for and what they need to know. Take the facts from the conversation so far; never invent details.
2. Match the relationship: family and friends get a warm, short message; colleagues get a clear, polite one.
3. Write in the recipient's language when the user mentions it (e.g. "she reads Vietnamese"); otherwise use the user's language.
4. Keep it short: a text is 2–4 sentences; an email gets a subject line and at most 5 lines.
5. Write dates in plain words ("Friday 30 October"). Use `current_time` if you need to work out a date.
6. Show the draft only. You can't send messages, so never claim you did. Offer one tweak, e.g. shorter, more formal, or another language.
